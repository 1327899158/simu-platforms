# 仿真通宣传页

入口：项目根目录 `仿真通-宣传页.html`。双击即可打开，品牌图标、手机展示图与示例头像均内嵌，无需安装依赖或联网。

也可在项目目录执行 `node outputs/promotion-preview/serve.cjs`，打开终端打印的本地预览地址；Ctrl+C 关闭预览服务器。服务器只向本机提供这一份 HTML。

## 项目依据

阅读 README、软件与方向字典、客户和工程师页面，以及案例展示、交付延期、长期合作、资料与售后相关文档。页面突出已实现的需求发布、方案报价、选择工程师、微信支付、沟通执行、成果交付与确认验收。

使用已有的“仿真通 / 仿真服务平台”名称。平台增长统计按用户要求填写演示数据，页面明确标注。协作视图为流程示意，不宣称软件官方合作关系。

2026-10-08 按用户指定的 `F:/01-仿真客 - 宣传首页.html` 调整六张服务卡、四张工程师案例卡、三张客户评价卡及深色多列底栏。参考中的工程师、成果、评分与评价作为展示示例，页面标注；正式发布时替换为已授权的真实资料。头像沿用参考提供的素材并内嵌，未导入参考的外部框架或脚本。

## 视觉方向

品牌图标来自 `miniapp/assets/brand-logo.png`。双手机主图来自用户提供的 `F:/e0944f28-69e7-4cc2-8d87-9051cfcc4682.png`，保留原始像素，通过 SVG 视窗隐藏顶部透明留白。

首屏为左侧项目价值、右侧双手机展示，下方展示 iOS、Android、Mac、Windows、微信小程序与对应图标。五个平台为大尺寸按钮，鼠标悬停或键盘聚焦时上浮放大，图标轻微旋转；点击后显示对应平台的“敬请期待！”弹窗。后续以平台规模和动态趋势图展示增长，再介绍服务范围、协作方式、代表案例、工程师成长路径与客户评价。

颜色：纸面 `#f3f7f8`、深海墨色 `#122937`、辅助文字 `#416575`、行动青色 `#137b8b`、青色 `#58c9d1`、暖橙 `#f28b5a`。图表通过青色折线与按领域区分的色环表达数据。

字体：数字与拉丁字母优先使用 Bahnschrift，中文使用 Microsoft YaHei / PingFang SC。字体均为本地系统字体，不加载远程字体。

数据区进入视野时播放一次数字、曲线和环形图动画。交互切换时重绘，减少动态效果设置下直接显示最终状态。不通过随机自动递增伪装成真实实时业务。

## 演示数据

按用户要求先填写：月访问量 38.6 万、月新增需求 1,286 个、专业工程师 2,680 位、累计项目交付 12,860 项。页面显示“演示数据”及说明，非真实业务统计。

修改 HTML 中的 `PLATFORM_DATA` 可调整趋势与分布；规模数字在 `data-counter` 属性中设置。正式上线时统一替换为核实后的业务统计。

## 可用交互

- 访问量 / 新增需求 / 项目交付趋势切换，以及近 6 / 12 个月切换。
- 月份明细支持鼠标、触摸和键盘提示；需求领域分布环形图。
- 四阶段合作流程切换。
- 移动端导航、FAQ 折叠、原生对话框，支持 Escape 与关闭后焦点返回。
- 五个平台的期待弹窗；底栏未配置的产品、社交与政策入口也显示期待弹窗。
- 底栏“发布需求”“工程师入驻”“加入我们”连接现有清单与指南，“服务领域”和“帮助中心”定位对应模块。
- 需求清单表单：校验、复制、下载 UTF-8 文本；浏览器不支持复制时自动下载。
- 工程师入驻指南及文本清单下载。

清单不上传、不自动发布，不写入后端。默认没有真实小程序链接或二维码。取得官方微信 URL Link 后，填写 HTML 中的 `SITE_CONFIG.miniappUrl`，对话框会显示“前往微信小程序”。现有项目源代码不提供可核实的公开访问链接，因此没有编造入口。

## 验证

原版验证脚本 `verify.cjs` 与报告 `verification.json` 记录上一版本的动态图表、清单复制下载和离线检查。

本次改版通过 Codex 浏览器工具在实际预览页检查：五个平台逐一弹窗、关闭与焦点返回、键盘放大效果、6 张服务卡 / 4 张工程师卡 / 3 张评价卡、七张内嵌头像加载、底栏功能入口，以及 1071、768、390、320px 布局。没有横向溢出，控制台无警告或错误。新报告见 `reference-update-verification.json`；首屏、案例和手机弹窗截图采用 `reference-update-` 或模块名称前缀保存。
