# 客服、公告与完单奖励验收

## 部署

先部署后端，再编译小程序。后端启动自动创建客服工单、工单消息、公告、规则启用时间表。管理员中的运营/客服角色（OPERATOR）和超级管理员可使用客服工作台及公告管理。

## 规则

- 新规则首次部署生效后完成且支付成功的订单，客户及选定工程师各自动获得500仿真币。约一分钟内入账；重启会补扫，重复执行不会重复发放。不补发历史订单。
- 奖励沿用现有仿真币权益账本，暂不抵扣支付、提现。后续售后不自动冲销此奖励。
- 客服入口位于双方“我的”。支持分类工单、最多5张截图、回复、关闭及重新打开；后台可受理、回复和标记处理完成。详情展示最近100条消息。FAQ沿用后台帮助内容。
- 公告可选择全部、客户或工程师，配置北京时间起止时间、编辑及下线。前端每分钟更新，横幅滚动、点击可读全文，到期隐藏。
- 关闭记录按本机账号和公告版本保存；编辑后作为新版本重新展示，不跨设备同步关闭状态。

## 验收步骤

1. 用测试订单完成支付及验收，等待约一分钟，双方进入卡券与仿真币查看各500币；反复刷新及重启服务不得重复奖励。旧完单和未支付订单不得获奖。
2. 客户提交包含截图的客服工单；运营账号进入客服工作台受理、回复；客户打开详情确认回复和截图可见。另一个客户不可读取该工单。
3. 关闭工单再重新打开，确认状态变化；后台操作应产生审计记录。
4. 创建“仅工程师”公告，起始时间设为当前之前、截止设为几分钟之后。工程师页面应出现顶栏横幅，客户不显示。点击阅读、关闭，再进入页面仍保持关闭。
5. 编辑该公告发布新版本，等待刷新后应再次出现；下线或过期后应隐藏。再测试客户角色、全部角色和未来生效时间。

以上需要在微信开发者工具及测试环境联调；本地自动测试不等于生产验收。
