# 收藏、帮助、举报、注销、合作与激励

## 实现范围

1. 收藏：工程师、案例、公开需求三类；分页、单项取消、批量移除。列表实时过滤失效内容；案例限定已完成订单、本人选中工程师、有效认证。定向需求不能被收藏为公开需求。
2. 帮助与反馈：管理员可新增/编辑/上下线 FAQ、帮助及关于我们正文。用户提交反馈并查看处理时间线；管理员受理、调查、结案，结果同步给提交人。
3. 举报：工程师资料、聊天、可见订单对方入口；原因、说明及最多5张截图。举报独立于黑名单，不自动封禁、扣分。管理员操作在事务中写入审计。
4. 注销：15天冷静期；申请前及到期执行前都校验订单、有效报价、退款、支付、纠纷、发票、未结反馈/举报、合作和管理员身份。期间可查阅、重新登录、退出及撤销，暂停新业务。执行时失效会话、解除登录标识，去除账号联系方式/头像及实名字段，移除案例、收藏和拉黑记录。交易、聊天、票据、证据及审计不级联删除；不是“删除一切数据”。
5. 合作：工程师设置折扣、响应时限、排期、修改次数和最低预算；客户阅读当前条款后提交意向，工程师接受才生效。修改设置不改旧合作，结束后可按新条款重新申请。双方均能结束合作，客户能撤销未接受申请。生效后客户发布定向需求，只有客户和指定工程师（以及有订单管理权限的管理员）可访问。已有订单不因合作结束而取消。
6. 激励：真实已完成订单的北京时间自然周排行榜、连续完单天数、首单/十单成就及周任务；后端核实资格，用户+任务+周期唯一约束，重复领取幂等。

## 明确边界

- 不调整支付金额。合作折扣为双方报价参考，由工程师在最终报价中体现；免费修改次数及响应承诺保存为条款，不自动扣款或自动处罚。
- 激励奖励状态为 RESERVED（预留权益），没有兑换、提现、抵扣能力。首单50币、累计十单100币、本周三单100币、连续三天完单80币为本版默认任务规则（连续任务还要求本周至少完成一单）。后续真实营销账本应消费唯一奖励编号，不能重复发放。
- 排行和任务统计当前仍为 COMPLETED 的订单，重新进入纠纷/撤销完成后不再计入当次资格；已登记奖励保留审计，不直接兑换现金，后续正式发放仍应再次核验。
- 申请注销后不自动撤回未成交需求或合作：需本人先处理前置事项。AGREED退款尚无真实退款对账闭环，仍按待处理财务事项阻挡注销，不把“工程师同意”当作已退款。
- 没有新增银行卡或资金钱包。本项目后续接入钱包、结算后，必须将待结算、余额和提现检查加入注销条件，再开放对应账户的注销。
- 注销默认取消后可重新申请，重新计时15天。去标识化后手机号可作为新账号登录，旧订单不会自动归并。未实现额外手机号重新注册冷却规则。
- 注销轮询每分钟运行，进程启动会补扫；容器停止或缩容至零时不执行，下一次启动补处理。未部署独立定时云函数。

## 证据安全

举报截图不用现有普通云存储目录。小程序先压缩（单张400KB以内），通过登录接口提交；后端使用 AES-256-GCM 和 IDENTITY_DATA_KEY 派生密钥加密保存到 support_evidence_blobs。读取仅允许上传者或 SUPPORT_MANAGE 管理员，管理员读取另记审计。被举报人不能通过用户接口读取提交人证据。

IDENTITY_DATA_KEY 必须稳定保管，随意更换会导致旧实名数据和新证据无法解密。截图预览会生成小程序临时本地文件，不产生公开云 fileID。未提交的证据暂保留，不自动删除。

原有订单文件仍受现有云存储规则约束：若线上云存储仍允许所有登录用户读取已知 fileID，后端定向需求鉴权不能阻止绕过后端的云存储直读。上线含敏感附件的定向交易前，需要单独部署私有存储和受控下载链路；本版没有擅改线上存储规则。

## 验收清单

### 收藏

客户收藏工程师及案例，工程师收藏公开需求；到“我的→我的收藏”切换类别并批量移除。用不同账号验证互不影响。将案例删除、工程师认证失效、需求停止报价后，刷新应隐藏。检查超过20条分页。

### 帮助与反馈

管理员工作台进入“帮助内容管理”新增 FAQ/关于我们，发布后用户刷新可见，下线后隐藏。用户提交反馈，管理员受理、调查、结案，用户记录显示同一结果。无权限管理员调用接口也应返回403。

### 举报

分别由客户、工程师从聊天举报对方，上传截图。第三个账号及被举报账号使用证据ID请求读取应404；管理员读取应有审计。跳过受理直接结案、重复结案应409。举报不应自动拉黑或封禁。

### 注销

有在途订单/有效报价/合作/未处理举报的账号申请应被拒绝。空闲测试账号申请后可查阅但不能新增需求、消息或领奖；退出后用原方式重新登录，进入“我的→注销账号”撤销可恢复。

仅在隔离测试库模拟 executeAfter 到期：确认去标识化、登录会话失效、案例停止展示、交易凭据保留。再测试到期前新增对该账号的未结举报：任务应暂缓执行并显示原因。不得在生产账号上缩短冷静期试验。

### 合作与定向需求

工程师设置9.5折、24小时、最低100元。客户提交意向前后更改设置，旧条款版本提交应409。客户不能替工程师接受。接受后创建定向需求：公开大厅和公开收藏不可见；第三个工程师直接请求详情、报价、附件应拒绝；指定工程师可报价，客户可选择并复用现有支付交付链路。结束合作不删除已有订单，不能再创建新的定向需求。

公开草稿与不同工程师的定向草稿分别保存，不可将旧公开附件草稿误发到定向需求中。支付金额仍等于最终报价，不自动叠加折扣。

### 激励

用真实测试订单完成验收，检查周完单、连续完单、排行榜变化；在北京时间周日/周一边界验证周切换。未达标直接调用领取接口应409；达标后并发/重复领取只生成一条业务记录。奖励为预留状态，不改变支付、余额或发票金额。

## 自动验证

执行 `node --test server/test/*.test.js`。新增测试覆盖公开范围、所有权、举报状态机与审计、证据加解密、合作条款版本、定向权限、任务资格与幂等、注销前置校验与执行。

这些为模拟数据库的单元/接口测试，不代替腾讯云MySQL迁移验证及微信真机联调。
