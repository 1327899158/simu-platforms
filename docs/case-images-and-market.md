# 案例图片与大厅热度

- 后端启动自动为 engineer_cases 增加 imageIds JSON 字段，无需清空或重建表。
- 先部署后端，确认 db-init-ok，再重新编译小程序。
- 案例最多 9 张独立上传的 JPG/PNG/WebP 图片，单张 5MB；必须确认公开授权。不能复用原订单附件、认证资料、聊天或售后证据。
- 图片预览先经过文件访问权限检查，再签发 5 分钟临时地址。案例停止展示后不能重新获取地址；已签发链接可能在有效期内仍可访问。
- 浏览量按订单 ID + 登录用户 ID 唯一计数，打开详情才计入；刷新、返回重进不重复计数。
- 热度 = 去重浏览量 + 3 × 非撤销报价数量，同分按发布时间、订单 ID 倒序。

## 验证

1. 已认证工程师选择本人已完成订单，上传 3 张展示图片，保存；编辑后应保留图片，允许移除和追加。
2. 另一账号打开工程师主页，检查缩略图及点击后的多图预览；从收藏案例入口也应可查看。
3. 移除案例后，另一账号刷新主页不再显示案例，原图片接口无法重新获取预览链接。
4. 上传 10 张、超过 5MB、非图片或使用其他用户文件 ID，提交应失败。
5. 工程师 A 打开同一需求两次只增加 1 次浏览；工程师 B 再打开增加 1 次。
6. 对比不同报价数、浏览量的需求，热门排序应按上述公式排列；撤销报价后刷新热度降低。
7. 检查大厅、订单、支付、认证和售后插画清晰显示，按钮仍可点击，工程师和案例收藏按钮为黄色五角星。
