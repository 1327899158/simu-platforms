# 交付后14天自动收货

- 以当前 `deliveredAt` 加14个自然日作为自动验收时间；驳回后重新交付会重新计时。
- 云托管启动后立即扫描，此后每60秒扫描。只处理未删除、未完成且仍为 `DELIVERED` 的订单，存在进行中纠纷或待处理/已同意退款时跳过。
- 订单状态和系统消息在同一事务中保存；订单详情倒计时使用同一截止时间计算规则，并根据服务端时间校准。
- 到期前3天内、1天内各发送一次订单会话提醒，计入客户未读数，点击可进入订单验收。复用 `delivery_reminders` 按订单、当前验收截止时间和阶段去重；驳回后重新交付会开始新一轮提醒。若服务恢复时只剩1天，直接发送1天提醒，不补发3天提醒；已到期不补发提前提醒。
- 现有待验收订单也使用其当前交付时间计算；部署时已经满14天且符合条件的订单会在首次扫描完成。

## 部署顺序

1. **先停用旧 `auto-complete-orders` 云函数定时触发器**，避免旧7天规则抢先执行；也可以部署本次提供的空操作兼容版本。
2. 部署 `server`，保持云托管至少1个实例运行，以保证每分钟的后台扫描。
3. 更新小程序，展示待验收倒计时；客户仍可提前手动验收。

不需要新增数据库字段。到期后通常在下一次扫描完成；服务暂停或故障时恢复后补处理，前端显示“已到期，等待系统确认”，不会自行把订单改成已完成。
