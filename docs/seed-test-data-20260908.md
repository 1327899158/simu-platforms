## 当前可见范围

本次只核对了本地建表代码。当前运行配置指向本机默认数据库地址，没有配置到云端的数据库连接，未查询线上表结构或记录。因此 SQL 与线上实际库的兼容性尚需核对。

## 导入前

1. 创建或选择独立测试数据库，并用当前后端完成建表/迁移。不要导入生产库：测试评价、订单和模拟支付会影响平台推荐、统计和等级。
2. 测试服务保持 `PAYMENT_MODE=mock`。不要用真实支付模式运行这些预置模拟支付单。
3. 使用 MySQL 客户端或能保证同一连接、遇错停止的 SQL 工具执行同目录 `seed-test-data-20260908.sql`。不要加 `--force`，不要在遇错后继续执行 COMMIT；同一连接执行 ROLLBACK。
4. 这是一次性种子：主键前缀 `seed260908_`，订单编号前缀 `TEST260908`。重复执行会冲突，脚本不会覆盖旧记录。不要为重试删除现有业务记录。
5. 云控制台若出现 Error 1064 且定位在第二条语句附近，可能是仅支持单条语句。不要盲目分段执行事务，请改用支持同一连接的客户端。

## 可选：查看目标库表概况（只读）

在目标数据库控制台执行：

```sql
SELECT DATABASE() AS current_database;
SELECT TABLE_NAME, ENGINE, TABLE_ROWS AS estimated_rows
FROM information_schema.TABLES
WHERE TABLE_SCHEMA = DATABASE()
ORDER BY TABLE_NAME;
```

TABLE_ROWS 对 InnoDB 是估算值，不是精确记录数。把表结构或查询结果提供给我时，请不要附带密码、Token、身份证、手机号或其他真实用户数据。
