# 卡券、仿真币抵扣与个人邀请

卡券与仿真币页参照 `F:/UI-仿真服务平台-折叠页面导航版.html` 的钱包布局，采用橙色余额卡、累计获得/净使用/冻结统计、任务入口、用途说明、活动礼包及收支明细。邀请页参照“34b.邀请好友海报”的紫色海报布局，显示个人小程序码、邀请码、邀请人数、首单人数、实际奖励及最近记录。

## 抵扣

- **100仿真币抵扣1元，1币对应1分**。客户可在订单支付页或订单详情的曝光购买区开启抵扣，最多使用可用余额及本次应付金额，无额外比例限制。仿真币不能提现或转让；优惠券仍保留领取、有效期和卡券列表，暂未开放支付抵扣。
- 新支付单先冻结仿真币；确认支付成功后转为扣除。真实微信支付只传现金差额；全额抵扣直接完成站内支付，不创建0元微信支付单。模拟支付不会收取现金，但会实际扣除站内仿真币。
- 订单服务总额与现金实付分别保存在 `payments.grossAmountFen` 和 `amountFen`，使用数量为 `coinAmount`。工程师收益、履约和完单奖励仍按原服务金额核对支付成功，抵扣差额属于平台营销补贴。这里未新增真实工程师结算或分账能力。
- 曝光仍为19元/100位不同工程师，服务总额 `order_exposures.amountFen`、现金差额 `cashAmountFen`、仿真币 `coinAmount` 分开保存。曝光现金实收统计排除抵扣部分。
- 取消支付单时先向微信查单并关单，再释放冻结；下单与取消共用订单锁，避免网关仍在创建支付单时提前释放。真实支付状态不明或关单失败时保留冻结，可稍后查询重试。
- 默认30分钟超时清扫：订单按选标时间超时回退报价；曝光按首次支付时间关闭待支付单。仅确认未支付且关闭后释放余额；已经支付则补记成功。超时时长沿用 `PAY_TIMEOUT_SEC`。
- 工程师同意退款时退回本订单尚未返还的抵扣币，现金退款仍沿用原登记流程；管理员将纠纷退款登记为 `PROCESSED` 时按退款额占服务总额的比例退币，向下取整至整币。重复登记不重复退币，累计不超过原抵扣币。已推流曝光费用不自动退款。
- `coin_spends` 记录冻结/使用/释放及已返还数量，`coin_refunds` 记录退回流水。余额由既有奖励减去净使用、冻结计算，不复制或重复发放历史奖励。用户锁和当前读防止并发重复花费。

## 个人邀请

首页邀请活动“查看活动”、登录弹窗“查看活动”和仿真币页的邀请入口均进入个人邀请海报页。用户可保存个人小程序码、保存完整海报、复制个人微信 URL Link，或使用微信原生分享按钮选择联系人。

`/api/invitations` 返回服务端生成的个人随机邀请码、分享路径及实际进度；`/qr` 调微信接口获取带 `scene=invite=<code>` 的小程序码，图片返回后保存到小程序本地文件，不依赖云存储桶公开权限。微信返回错误JSON时明确报错并允许重试，不伪造二维码。`/link` 生成30天有效的个人链接，接近到期、过期或切换小程序版本时重新生成。

游客首页、应用启动与唤醒捕获邀请码，登录/注册成功后调用 `/api/invitations/accept`。首次有效入口优先保留，24小时后过期；网络失败保留并在登录/首页重试。服务端只接受新账号注册后10分钟内绑定，禁止自邀，一个账号只能绑定一位邀请人；活动 `invite` 必须启用且动作为 `SHARE`。绑定成功给邀请人50币，后续好友首笔已支付订单完成（作为客户购买或工程师承接）后追加250币。首单奖励通常在一分钟的清扫周期内到账。点击分享本身不发币；历史账号不补计邀请奖励。

邀请关系及个人入口保存于 `invitation_relations`、`invitation_codes`，奖励复用 `incentive_rewards` 的业务唯一键，注册和首单分别幂等发放。

## 部署与验收

1. 同时发布新版后端与小程序。后端启动或 `npm run migrate` 自动创建新表、添加抵扣字段，并将奖励业务编号 `periodKey` 扩为64字符以容纳订单/用户ID。旧支付单通过 `COALESCE` 保持兼容，无需重新发放历史奖励。
2. 个人小程序码与链接复用登录模块的微信令牌：优先云托管注入的 `cloudbase_access_token`，否则使用 `WX_APPID`、`WX_APPSECRET` 获取应用令牌。`INVITE_ENV_VERSION` 默认为 `release`，体验版可设置 `trial`，开发版为 `develop`；正式上线恢复 `release`。小程序码开启页面检查，目标游客首页需要已经存在于微信发布版本中。URL Link 接口是否可用、权限与额度以该小程序后台实际返回为准。
3. 本地自动化覆盖抵扣金额、余额不足、并发使用、支付重试、全额抵扣、取消、网关创建与取消并发、超时、退款幂等、曝光现金核验、邀请绑定与奖励去重、微信图片错误处理、链接缓存、邀请码捕获和数据库迁移。页面静态预览检查360与430像素宽度；不代替微信真机验证。
4. 部署环境验证 MySQL 迁移、真实微信收款、个人码扫码注册、链接打开注册、微信联系人分享以及海报/小程序码保存到相册。邀请接口和真实支付的本地测试使用模拟网关，没有请求生产微信接口或数据库。
