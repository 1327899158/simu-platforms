# 登录邀请弹窗

复用现有 `home_campaigns` 中 `invite`、`SHARE` 活动及其管理员配置的标题和规则。活动下线时不弹出；读取失败不阻断登录，重新进入首页可重试。

客户和工程师成功登录（微信、账号密码、手机号验证码）或注册后，进入首页显示一次。保存登录状态重新启动小程序后，首次进入首页也显示一次。点击右上角“×”、遮罩、“稍后再说”或“分享给好友”后关闭，同次登录切换页面、从后台回来或刷新资料不会再次显示；重新登录会再次显示。

分享按钮携带服务端生成的个人邀请码打开游客首页，“查看活动”进入个人邀请海报页。邀请归属核验与注册50币、首单完成250币的自动奖励已接入；分享本身不发币，规则以实际入账为准。具体流程见 [仿真币与邀请说明](coins-and-invitations.md)。

工程师打开此弹窗时暂停首页曝光卡片的可见上报，关闭后恢复，避免把遮挡的需求计为已推流。异步活动请求返回时会检查当前账号、登录会话和页面是否仍可见，避免退出或切换账号后显示旧弹窗。

需同步发布新版小程序与后端，后端启动自动迁移个人邀请与抵扣表。真机验收时分别测试两种角色及各登录方式，确认每次登录只展示一次、所有关闭方式有效、分享卡片带个人邀请码打开游客首页、下线活动不显示。
